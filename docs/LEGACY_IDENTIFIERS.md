# Legacy identifiers

Some executable cells, paths, tables, and frozen outputs still contain `H1`, `h1`, or `H_priv`. These are provenance identifiers from earlier stages of the project.

They have **not** been globally renamed inside executable code because doing so would break file paths, saved-schema compatibility, hashes, or exact reproduction of frozen analyses. Repository-facing titles and descriptions instead use the current matched-information and validation framing.
